This project employed multiple methods: 1) Textual Analysis; 2) Trend Analysis; 3) Critical Discourse Analysis. The data consist of posts in Arabic collected from Twitter (X) and Facebook. X data were acquired in the form of CSV files. Facebook (FB) data were acquired from the front end through a user account. Therefore, the FB corpus required extensive cleaning and preparation.
The FB data preparation steps are found in (https://github.com/nadimashkieh/Vaccine_Hesitancy_among_Arabic_Social_Media_Users-/new/main?filename=README.md#:~:text=fb_data_prep_Github_version.ipynb). The next step was to prepare, clean, and reconcile both data corpuses for use in the analytical steps. Please refer to the code in (https://github.com/nadimashkieh/Vaccine_Hesitancy_among_Arabic_Social_Media_Users-/new/main?filename=README.md#:~:text=DataPrepCombinedGithub_version.ipynb) for this step.
Now that the data from both corpuses are compatible, method 1, Textual Analysis can be executed using codes in the file https://github.com/nadimashkieh/Vaccine_Hesitancy_among_Arabic_Social_Media_Users-/new/main?filename=README.md#:~:text=TextualAnalysis_Github_version.ipynb. Note that data frames were saved into files and opened for analysis whenever needed, to avoid repeating the initial computational steps every time.
The execution of the method 2 of Trend Analysis, or Time Series is now possible using https://github.com/nadimashkieh/Vaccine_Hesitancy_among_Arabic_Social_Media_Users-/new/main?filename=README.md#:~:text=TimeSeries_Github_version.ipynb
Lastly, method 3 of Critical Discourse in this project analyzed a sample of the 2 corpuses at micro linguistic level, that does not involve computational methods. However, to pick a representative sample for the analysis, a sorting method along the number of "Likes" associated with each post in both corpuses was used following the code in https://github.com/nadimashkieh/Vaccine_Hesitancy_among_Arabic_Social_Media_Users-/new/main?filename=README.md#:~:text=Sorted_Github_version.ipynb
